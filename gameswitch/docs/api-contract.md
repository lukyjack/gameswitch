# GameSwitch API contract

All JSON. Errors: `{error: string, errorId?: string, requestId?: string}`. Auth mutations require same Origin and `X-CSRF-Token` from session. Cookies are HttpOnly, SameSite Strict. UI is German. Runtime defaults to explicitly labelled sandbox; production adapter is PufferPanel.

Every request reaching GameSwitch receives a server-generated UUID in `X-Request-ID`; a supplied request-ID header is ignored. Handled server errors and uncertain console/admin delivery include `errorId` and `requestId` plus a safe message containing the error ID. With the default logger the error ID equals the originating request ID. Ordinary validation/authentication/conflict errors can still contain only `error`. These IDs correlate private diagnostics; they do not grant access to logs or trigger retries. No diagnostics-reading API is implemented.

- GET `/api/session` -> `{authenticated, setupRequired, csrfToken?, username?, mode: 'sandbox'|'pufferpanel'}`
- POST `/api/setup` `{token, username, password}` -> session. One-time local bootstrap token appears in the development console; production writes it privately to `DATA_DIR/setup-token`.
- POST `/api/login` `{username,password}` -> session (csrfToken included)
- POST `/api/logout` -> `{ok:true}`
- GET `/api/state` -> `{mode, profiles, activeProfileId, job, backups, events, host: {name,cpuCores,memoryMb,reservedMemoryMb}, security: {authenticated:true,csrf:true,localOnly:boolean}, catalog}`
- profile -> `{id,name,gameId,version,loader,modpackId?,modpackVersion?,modpackName?,modpackVersionName?,javaVersion?,minimumMemoryMb?,recommendedMemoryMb?,collectionId?,gamemode?,map?,worldName?,queryPort?,beaconPort?,maxPlayers,memoryMb,port,serverId?,installed,status:'stopped'|'running'|'unknown',createdAt,serverPasswordSet?,rconPasswordSet?,consoleInput,adminKind}`. FTB metadata is resolved server-side. GMod `gamemode` is `sandbox` or `terrortown`. Secret values are excluded by an explicit response-field allowlist.
- catalog -> `[{id,name,description,kind:'minecraft'|'steam'|'native',loaders:string[],defaultPort,defaultMemoryMb,available,consoleInput,adminKind,minMemoryMb,maxPlayers,defaultVersion?,defaultQueryPort?,defaultBeaconPort?,notice?,unavailableReason?}]`. Available games: Minecraft, GMod, Valheim, Terraria and Factorio. Squad and FS25 are visible with blocking reasons; creation and activation remain unavailable.
- POST `/api/profiles` `{name,gameId,version,loader,modpackId?,modpackVersion?,collectionId?,gamemode?,map?,worldName?,queryPort?,beaconPort?,serverPassword?,maxPlayers,memoryMb,port,eulaAccepted?}` -> `{profile}` (201). No arbitrary install commands/URLs/templates accepted. Server IDs are generated by the backend. `serverPassword` is required for Valheim/Factorio, 8–64 ASCII letters/digits/underscore/hyphen, and written only to the private secret store. `worldName` is limited to 1–40 letters/digits/underscore/hyphen. Steam games use `latest`; native versions are pinned to Terraria 1.4.5.8 and Factorio 2.1.24. Validate each game's RAM/player limits and complete port range, including reserved administration ports and secondary ports. FTB IDs pin a public pack release; Java heap minimum includes an additional 2048 MB container allowance, maximum heap is capped at the pack recommendation, and initial heap is at most 2048 MB.
- POST `/api/profiles/:id/activate` -> `{job}` (async install/switch with serialized global job lock)
- POST `/api/profiles/:id/restart` `{}` -> `{job}` (202). Only the currently running, installed profile; no pending restore or safety backup for another profile. The serialized job persists its safety obligation, saves, gracefully stops, explicitly confirms stopped status, completes a full `Vor-Neustart` backup, rechecks all profiles and starts the same profile. No install/reinstall. Save/stop/status/backup failures prevent start; no automatic rollback or blind retry. Process started does not mean the game has finished loading. Nonempty request bodies are rejected.
- POST `/api/profiles/:id/stop` -> `{job}`
- POST `/api/profiles/:id/backup` -> `{job}` (only stopped; UI explains)
- POST `/api/backups/:id/restore` -> `{job}` (only stopped; retain pre-restore backup)
- GET `/api/profiles/:id/console` -> `{lines:string[]}`
- POST `/api/profiles/:id/console` `{command:string}` -> `{ok:true}`. Minecraft, GMod, Terraria and Factorio; the Squad transport is prepared but that game is unavailable. Valheim has output only. Authenticated same-Origin/CSRF request, 30 commands/minute; one nonempty line of at most 1024 characters without control characters. An optional leading slash is normalized; Factorio receives exactly one leading slash. Other games also reject semicolons and quoted command names. Requires a fresh running status and the exclusive lifecycle gate. Common top-level lifecycle verbs are rejected as a convenience, not a sandbox against arbitrary game/mod commands. The audit persists only the verb before dispatch. Acceptance is not proof of game execution. An uncertain dispatch returns safe 502 wording and is never retried automatically.
- POST `/api/profiles/:id/admin` `{steamId:string,role:'admin'|'superadmin'|'user'}` -> `{ok:true,notice:string,requiresRestart:boolean,simulated?:boolean}`. Shares authentication, CSRF, Origin, command rate, durable argument-free audit and lifecycle gate. Strictly canonicalizes SteamID2/SteamID64 for public individual accounts; usernames and extra fields are rejected. GMod requires an installed, running profile with ULX/ULib; emits one fixed `ulx adduserid ... admin|superadmin` or `ulx removeuserid ...` command. Valheim accepts `admin|user` only, requires a confirmed stopped profile, backs up and merges `saves/adminlist.txt` using `Steam_<ID64>`, preserving other entries. It never restarts the game; changes apply by the next normal start. Prepared Squad support merges only its managed `GameSwitch_Admin` assignment in `Admins.cfg`, but is not a launchable game. File-write uncertainty returns 502 without automatic repetition. Minecraft uses `op Name`/`deop Name` through its console; Factorio uses `/promote ExactPlayerName`; vanilla Terraria has no equivalent operator role.
- GET `/api/catalog/modpacks?q=...` -> `{hits:[{id,slug,title,description,downloads,versions:string[]}]}` Modrinth only
- GET `/api/catalog/modpacks/:id/versions` -> `{versions:[{id,name,version,gameVersions,loaders}]}`
- GET `/api/catalog/ftb?q=...` -> `{hits:[{id,slug,title,description,downloads,versions,provider:'ftb'}]}` via fixed official FTB API.
- GET `/api/catalog/ftb/:id/versions` -> `{pack:{id,name},versions:[{id,name,version,gameVersions,loaders,javaVersion,minimumMemoryMb?,recommendedMemoryMb?}]}`. Only public release versions with supported Java runtimes.
- GET `/api/catalog/minecraft-versions` -> `{versions:string[]}`

job -> `{id,type,status:'running'|'completed'|'failed',profileId,steps:[{label,status:'pending'|'running'|'completed'|'failed'}],requestId?,errorId?,error?,createdAt}`. API-created jobs retain the initiating request ID. Failed jobs contain a fixed, classified message with `Fehler-ID` and `errorId`; raw upstream messages are excluded. The request can have returned 202 before this asynchronous failure appears in state.
backup -> `{id,profileId,profileName,name,createdAt,status:'completed',runtimeId?}`
event -> `{id,time,level:'info'|'warning'|'error',message}`

Client polls state every 2 seconds during jobs, 8 seconds idle. UI is an honest control panel: no fabricated real CPU/players/uptime metrics; sandbox clearly labelled.
